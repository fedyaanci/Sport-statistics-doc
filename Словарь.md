# Словарь предметной области

Словарь задаёт единый язык проекта «Спортивная статистика». В документации, интерфейсах и программном коде приведённые термины должны использоваться в указанном значении.

| Термин | Определение |
|---|---|
| Архивные данные | Данные завершённых матчей и прошлых сезонов, перемещённые в менее дорогое хранилище, но доступные для поиска и восстановления |
| Авторитетный источник | Источник, данным которого система отдаёт приоритет при разрешении противоречий определённого типа |
| Вид спорта | Набор правил, типов участников, событий и статистических показателей, по которым проводятся соревнования |
| Видеомомент | Видео или ссылка на видеофрагмент, привязанные к матчу, временному интервалу и при необходимости к конкретному событию |
| Внешний источник данных | Сторонняя спортивная база или система, передающая сведения через интеграционный интерфейс |
| Игрок | Спортсмен, участвующий в матчах самостоятельно или в составе команды |
| Индивидуальный показатель | Рассчитанная характеристика результата отдельного игрока за матч, турнир, сезон или выбранный период |
| Инфографика | Визуальное представление выбранных статистических показателей, сформированное для просмотра или экспорта |
| Команда | Группа игроков, выступающая как один участник соревнования |
| Командный показатель | Рассчитанная характеристика результата команды за матч, турнир, сезон или выбранный период |
| Корректировка | Контролируемое исправление ранее зарегистрированного факта с указанием причины, автора и времени изменения |
| Ключевой момент | Событие матча, отмеченное пользователем или правилом системы как существенное для результата или обзора |
| Лига | Объединение участников и турниров, проводимых в рамках общей организационной структуры |
| Матч | Спортивное событие между определёнными участниками, имеющее расписание, статус, результат и набор зарегистрированных событий |
| Метрика качества прогноза | Числовой показатель, используемый для оценки точности прогнозной модели на известных результатах |
| Онлайн-табло | Представление текущего состояния матча и его показателей, автоматически обновляемое по мере поступления событий |
| Оператор данных | Пользователь, имеющий полномочия вводить, проверять и корректировать спортивные данные |
| Официальный результат | Итог матча, подтверждённый организатором или другим назначенным авторитетным источником |
| Позиция игрока | Функциональная роль игрока на поле или площадке в рамках конкретного вида спорта и состава |
| Пользователь | Человек или внешняя система, взаимодействующие с продуктом после идентификации либо через публичный доступ |
| Прогноз | Рассчитанная оценка вероятного результата будущего матча, полученная на основании выбранных данных и версии модели |
| Происхождение данных | Сведения об источнике, времени получения и способе создания статистического факта |
| Расписание | Набор запланированных матчей с датой, временем, местом и участниками |
| Режим реального времени | Режим, при котором принятое событие матча попадает в пользовательское представление в пределах установленной задержки |
| Роль доступа | Набор разрешений, определяющий доступные пользователю операции и данные |
| Сезон | Ограниченный период проведения соревнований, используемый для группировки матчей и статистики |
| Событие матча | Зафиксированное во времени доменное действие, способное изменить состояние матча или его статистику, например гол, штраф или замена |
| Состав | Перечень игроков команды, заявленных на матч или турнир, с указанием их позиций и статуса участия |
| Сравнение | Представление показателей двух или более игроков либо команд за сопоставимые периоды и при одинаковых правилах расчёта |
| Статистический факт | Исходное измерение или зарегистрированное событие, на основании которого рассчитываются показатели |
| Статистический показатель | Именованная величина с единицей измерения и правилом расчёта, применимая к определённому виду спорта |
| Статус матча | Текущее состояние жизненного цикла матча: запланирован, идёт, приостановлен, завершён, отменён или перенесён |
| Турнир | Организованная серия матчей с участниками, регламентом и правилами определения результата |
| Участник матча | Игрок или команда, выступающие в конкретном матче |
| Фильтр | Условие отбора данных по периоду, виду спорта, лиге, турниру, команде, игроку или другому признаку |
| Отчёт | Документ или набор данных, сформированный по выбранным показателям, периоду и формату представления |
| Версия модели | Идентификатор алгоритма и параметров, с которыми был рассчитан прогноз |
| Версия статистики | Состояние статистических данных на определённый момент, позволяющее восстановить историю исправлений |
| Импорт | Процесс получения, проверки и сохранения данных из внешнего источника |
| Дедупликация | Обнаружение и предотвращение повторного сохранения одного и того же события или статистического факта |
| Агрегация | Расчёт итогового показателя из набора статистических фактов за выбранный период или уровень детализации |

## Правила употребления терминов

1. **Событие матча** не является готовым агрегированным показателем. Событие служит основанием для расчёта статистики.
2. **Статистический факт** хранит исходное значение и происхождение, а **статистический показатель** определяет смысл и правило расчёта величины.
3. **Корректировка** не должна физически уничтожать предыдущую версию данных.
4. **Прогноз** не является официальным результатом и должен сопровождаться версией модели.
5. При **сравнении** участников должны использоваться одинаковые показатели, периоды, единицы измерения и правила расчёта.
6. Термин **реальное время** означает соблюдение установленного предела задержки, а не абсолютно мгновенную обработку.
