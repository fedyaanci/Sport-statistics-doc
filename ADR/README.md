# Реестр архитектурных решений

Проект: **«Спортивная статистика»**.

## Стандарт именования

Используется формат `ADR-NNN-краткое-наименование.md`, где `NNN` — неизменяемый последовательный номер. Дата решения хранится внутри файла. Переименование принятой записи и повторное использование её номера не допускаются.

## Статусы

- **Предложено** — решение обсуждается и ещё не влияет на реализацию.
- **Принято** — решение обязательно для текущей реализации.
- **Заменено ADR-NNN** — решение больше не применяется; ссылка указывает заменяющую запись.
- **Отклонено** — рассмотренное решение не принято.

Принятая ADR не редактируется так, чтобы изменился смысл решения. Новое решение оформляется отдельной записью и заменяет старую.
