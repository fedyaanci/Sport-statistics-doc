# Спортивная статистика — лабораторная работа №3

Архитектурные факторы, введение и единый словарь для проекта «Спортивная статистика». Дата: 18 ноября 2026 года. Статус: проект требований к будущей реализации.

## Документы для сдачи

1. [Введение](<1. Исходные сведения/Введение.md>) — назначение, пользователи, границы и контекст.
2. [Архитектурные факторы](<1. Исходные сведения/Архитектурные факторы.md>) — функциональность, измеримые качества, ограничения и принципы.
3. [Словарь](<1. Исходные сведения/Словарь.md>) — единые определения предметных терминов и состояний.

Дополнительно: [обоснование небольшого стека](<Пояснения/Выбор стека.md>) и [краткий рассказ для защиты](<Пояснения/Как защитить.md>).

## Скачать актуальную копию

Выполните команду из родительской папки, в которой ещё нет каталога `Sport-statistics-doc-lab3`:

```bash
git clone --branch main --single-branch https://github.com/fedyaanci/Sport-statistics-doc.git Sport-statistics-doc-lab3
```

Откройте созданную папку `Sport-statistics-doc-lab3`. Клонирование в новую папку не обновляет ранее скачанную локальную копию. На GitHub текущая версия открывается по адресу [ветки main](https://github.com/fedyaanci/Sport-statistics-doc/tree/main).

## Как читать требования

Функциональные требования обозначены `F`, качества — `PER`, `SCA`, `DAT` и другими префиксами, ограничения — `LIM`, принципы — `PRN`. Ссылки на `US-…` открывают карточки второй лабораторной. Требование относится к указанному релизу и последующим версиям; это срок его готовности.

Общая цель и функции взяты из исходных материалов. Числа нагрузки, задержек, сроков ссылок и режима эксплуатации — явно выделенные проектные допущения для небольшого пилота. Они задают проверяемый вариант требований, но не выданы за слова преподавателя или результаты уже выполненных испытаний.

Для чтения достаточно редактора Markdown или GitHub. Все ссылки между документами относительные, а ссылки на ES и USM открывают соответствующую Miro-доску.
